# The MET — Museum Landing Page

A responsive landing page for The Metropolitan Museum of Art. The website helps visitors plan a museum visit, browse current exhibitions, explore online resources, and contact The Met locations.

## Live Demo

[The MET landing page](https://GoatSpirit.github.io/layout_landing-page/)


## Design Reference

[The MET Figma design](https://www.figma.com/file/lSR1m42L9YwzQwzzxKwHpw/THE-MET)

## Technologies Used

### Core

- HTML5 — semantic page structure
- SCSS — styling, variables, media queries, and responsive layouts
- JavaScript — menu navigation behavior

### UI and UX

- CSS Grid and Flexbox — responsive page layout
- Google Fonts — Cinzel font family
- CSS transitions — hover effects and smooth visual feedback
- Smooth scrolling — section navigation
- Responsive design — desktop, tablet, and mobile layouts

### Development and Quality

- Vite — local development and production build
- Sass — SCSS compilation
- ESLint — code quality checks
- Stylelint — SCSS linting
- Prettier — code formatting
- Cypress — browser testing setup

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/<your-github-username>/layout_landing-page.git
cd layout_landing-page
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project locally

```bash
npm start
```

### 4. Build for production

```bash
npm run build
```



## Features

- Responsive landing page based on The Metropolitan Museum of Art design
- Full-screen hero section with museum branding
- Header phone action with visible phone details on hover
- Mobile-friendly menu with smooth section navigation
- Museum hours for The Met Fifth Avenue and The Met Cloisters
- Exhibition gallery section with image hover animations
- Online resources section with three explore cards
- Contact section with clickable phone numbers, email links, and Google Maps addresses
- Contact form with required fields and proper input types
- Sticky footer with background image effect
- Layout optimized for desktop, tablet, and mobile screens
